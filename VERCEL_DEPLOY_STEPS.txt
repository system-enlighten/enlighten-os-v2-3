enLIGHTen OS v2.11.13 — Vercel-ready frontend

WHAT WAS ADDED
- api/index.js: a Vercel Serverless Function that proxies /api requests to the existing Google Apps Script Web App.
- The existing frontend still calls /api, so App.jsx does not need to expose or change the backend URL.
- The existing Vite development proxy remains in vite.config.js for local development.

DEPLOY TO YOUR EXISTING GITHUB REPOSITORY
1. Keep your working Google Sheet and Apps Script deployment unchanged.
2. In GitHub, open the existing enLIGHTen repository on branch main.
3. Replace the OLD frontend repository contents with ALL files/folders from THIS folder.
   The repository root should contain at least:
     api/
     src/
     index.html
     package.json
     vite.config.js
4. Commit the changes to main (example message: Deploy enLIGHTen OS v2.11.13 Vercel-ready).
5. Vercel should automatically create a new deployment from that commit.
6. In Vercel, confirm Build settings use Vite / npm run build / dist (automatic Vite detection is fine).
7. After Status = Ready, open the production URL and hard refresh (Ctrl+Shift+R).

IMPORTANT
- Do NOT upload the AppsScript_Backend_v2.4 folder to Vercel/GitHub as part of this frontend deployment.
- Do NOT change DATABASE_SPREADSHEET_ID if your Google Sheet + Apps Script are already working correctly.
- If your Apps Script /exec deployment URL changes later, update APPS_SCRIPT_URL in api/index.js AND vite.config.js.
