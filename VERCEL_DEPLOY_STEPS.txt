DEPLOY THE FRONTEND FROM GITHUB

1. Extract Enlighten_OS_GitHub_Frontend.zip.
2. Copy its contents into the existing frontend repository root, preserving
   folders and filename case. Commit the files to the branch Vercel deploys.

   index.html
   package.json
   vite.config.js
   vercel.json
   api/
   public/
   src/
     main.jsx
     App.jsx
     StudioTheme.css

3. Check the committed files in GitHub. index.html and the src directory must
   be siblings. Open src/main.jsx in GitHub to confirm it was uploaded.
4. Build from that same directory in Vercel. If the frontend files are at the
   repository root, use the repository root as the Root Directory. Use the
   existing Vite build settings (npm run build, output dist).
5. Verify that the new deployment builds from the new GitHub commit.

Use the complete ZIP for a project backup. Its deployable frontend is under
System 224.0/Frontend. The existing Apps Script deployment and Vercel environment
variables can be reused for this frontend update.
